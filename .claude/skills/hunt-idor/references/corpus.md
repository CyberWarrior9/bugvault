## Queries

Full-text over report bodies (68.1 MB across 9,742 reports):

```sh
sqlite3 vault/_data/corpora/h1-corpus.sqlite3 \
  "SELECT report_id, substr(title,1,70) FROM reports_fts \
   WHERE reports_fts MATCH 'YOUR TERMS' LIMIT 20;"
```

Every report for this skill's classes:

```sh
sqlite3 vault/_data/corpora/h1-corpus.sqlite3 \
  "SELECT id, bounty, title FROM reports \
   WHERE primary_class IN ('Access Control & IDOR') ORDER BY bounty DESC;"
```

Recorded payloads (25) with their technique and parameter. Read these as *what was disclosed*; the engine still generates its own through `fields.packet`/`record_payload` so authorship is recorded:

```sh
sqlite3 vault/_data/corpora/h1-corpus.sqlite3 \
  "SELECT technique, parameter, payload, report_url FROM payloads \
   WHERE class_name='idor' LIMIT 40;"
```
